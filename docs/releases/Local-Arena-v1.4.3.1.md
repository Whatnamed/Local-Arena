# Local Arena v1.4.3.1 正式版更新公告

> 已发布版本的说明记录，不是当前状态。长期事实见 [`docs/README.md`](../README.md)。

![Local Arena v1.4.3.1 更新公告](assets/local-arena-v1.4.3.1-update.png)

本次更新以 `v1.4.2.5` 为稳定基线，完整合并上游 `v1.4.3` 人机更新，并完成 Local Arena 品牌、面板、个性化、离线匹配、饰品和安装更新链路的整合

## 从 CS2BotImproverPlus 到 Local Arena

- 项目正式更名为 Local Arena
- 更换应用名称、项目 Logo、程序图标和版本显示
- 更新下载、版本检查和发布地址迁移至 Local Arena 仓库
- 支持从旧版 `CS2BotImproverPlus.exe` 平滑迁移至 `LocalArena.exe`
- 关于页面加入 BHCN STUDIO 开发与版权信息
- CS2-Bot-Improver 仅作为第三方开源项目和上游来源展示

## 全新面板与视觉系统

- 全面重构面板布局和视觉层级
- 减少硬边框、卡片堆叠和页面空白
- 重做主页、设置、语言、命令、预设、匹配和关于页面
- 优化分段控件、状态提示、更新横幅和设置入口
- 增加统一的页面切换动画与交互反馈
- 语言设置调整为更清晰的一行式布局
- 机器人预设与机器人物品配置重新整理，提升空间利用率
- 关于页面拆分为第三方开源项目、用户协议、隐私政策和开发信息
- 指南中的 16 张图片已替换为当前版本的真实面板界面

## 个性化主题系统

- 默认主题调整为 Local Arena 赤陶橙红
- 新增天蓝、橙红、黑白、草绿等颜色预设
- 支持使用调色盘实时调整强调色和界面配色
- 支持调整界面密度、圆角、阴影、风格和动画强度
- 支持上传自定义背景图片并设置位置、适配方式、遮罩和模糊程度
- 支持上传 `TTF`、`OTF`、`WOFF` 和 `WOFF2` 字体
- 支持修改侧边栏显示名称和侧边栏 Logo
- 正式产品名称、版本号和系统级品牌信息不会被个性化设置修改
- 支持个性化预设导入与导出

## 战队主题

- 新增 Falcons、Vitality、FURIA、Spirit、Natus Vincere、G2、MOUZ、FaZe 和 TYLOO 主题
- 战队主题会同步调整背景、Logo、侧边栏名称、强调色和界面配色
- 深色主题增加浅色内容隔层和文字遮罩，改善文字可读性
- 侧边栏、主要页面和设置页面统一适配战队风格
- 战队主题可以与离线匹配中的对手选择联动

## 上游 v1.4.3 人机升级

- 完整合并上游 `v1.4.3` 的 BotAI、BotState、BotBuy、NadeSystem 和 BotRandomizer 更新
- 保持上游人机决策、移动、购买、瞄准和投掷物行为
- Local Arena 的面板、匹配和饰品功能通过独立边界接入
- 避免饰品系统和比赛运行状态覆盖上游核心人机逻辑
- 同步更新 Windows 与 Linux 原生签名和兼容处理

## 瞄准与战斗行为

- 支持 `head`、`body` 和 `mixed` 三种瞄准模式
- 使用托管 CCSBot Schema 调整瞄准目标
- 不再依赖高频原生 Hook 或固定内存偏移
- Schema 连续失败时会自动停止托管瞄准覆盖
- 托管覆盖停止后自动回落至上游 BotAI，避免人机停止射击
- 新增回合级瞄准统计和运行状态记录
- 修复部分情况下选择爆头模式后仍持续瞄准身体的问题
- 改善机器人重新装备、换弹中断和自动检视时的状态衔接

## 购买行为

- 恢复上游 `v1.4.3` 完整购买流程
- CT 步枪选择约为 `47% M4A4`、`47% M4A1-S` 和 `6% AUG`
- T 阵营按照上游规则处理 AK-47 与 SG 553 的替换选择
- 修复机器人过度集中购买 AUG 和 SG 553 的问题
- 购买延迟回调增加玩家、回合和地图代际验证
- 玩家离开、回合结束或地图变化后，旧回调不会继续操作失效对象

## 投掷物与机器人状态

- 新增 `bot_nades less` 投掷物强度
- Less 模式限制每个机器人每回合可使用的投掷物数量
- 保留完整、减少和关闭等不同投掷物控制方式
- 优化出生、购买、换枪、拾取和快速重生后的状态恢复
- 减少机器人控制器替换期间出现的失效引用和延迟调用

## Bot 饰品系统

- BotRandomizer 升级为全新的机器人饰品系统
- 更新枪皮、刀具、手套、探员和音乐盒目录
- 机器人武器最多可以生成五张贴纸
- 机器人武器支持挂坠和武器感知挂点
- 在武器创建前准备完整经济属性，减少生成后的重复修改
- 普通购买和 BotBuy 替换武器均可应用机器人饰品
- `br_reroll` 调整为下一次安全出生时生效
- 禁止对存活机器人进行即时热重随机，降低无效实体和崩溃风险
- `skins`、`agents`、`music` 和 `profiles` 开关继续兼容

## 玩家饰品边界

- 玩家普通枪皮、刀具、手套和音乐盒功能继续保留
- 玩家 CT 与 T 独立配置继续保留
- BotRandomizer 只处理机器人，PlayerKnifeCustomizer 只处理真人玩家
- 玩家贴纸的数据结构和界面框架仍然保留
- 玩家贴纸原生应用链路在本正式版继续禁用
- 当前版本不会向真人武器写入贴纸属性
- 玩家挂坠暂未开放配置入口
- 贴纸功能关闭不会影响普通枪皮、刀具、手套和音乐盒应用

## 离线匹配与比赛运行

- 保留 Local Arena 离线匹配、比赛记录、Demo 和 OpenRating 功能
- 新增受管比赛运行状态
- 阵容修改期间暂停购买和托管瞄准
- 阵容稳定后自动恢复完整上游购买与瞄准
- 减少比赛启动阶段替换机器人控制器产生的延迟回调错误
- 保留比赛双方阵容、预设和战队主题联动

## 安装与一键更新

- 修复部分用户从旧版本开始安装按钮长期变灰的问题
- 面板会独立实时复检 CS2 进程，不再完全依赖旧状态快照
- 完整扫描失败时仍会刷新必要的运行状态
- 首次安装页面新增重新检测和诊断导出入口
- 后端安装前继续检查 CS2、Steam 文件活动和安装事务状态
- 面板更新与插件更新整合为一键更新
- 任一组件存在更新时都会显示可用的安装入口
- 只有插件更新才要求有效 CS2 目录并关闭 CS2
- 面板和插件分别验证签名、文件大小和 SHA-256

## 稳定性与验证

- 环境 Doctor 24 项检查通过
- MatchCore 和 PlayerKnifeCustomizer 测试通过
- Rust 测试结果为 `106 passed / 0 failed / 1 ignored`
- 贴纸编辑器和首次安装门控测试通过
- BotRandomizer 单项目编译为 0 警告和 0 错误
- 前端、C# 插件、Rust 后端和 Tauri Release 构建通过
- Workspace Verify、包内容审计和独立启动冒烟测试通过
- 本次验证不代表所有系统环境下绝对不会发生崩溃
- 若遇到闪退、安装按钮不可用或人机异常，请优先导出诊断包并附带复现步骤

## 从 v1.4.2.5 升级

- 建议关闭 CS2 和 Steam 文件操作后再执行更新
- 原有面板设置、比赛数据和玩家饰品配置将继续保留
- 旧版程序名称会迁移至 Local Arena
- 更新后建议重新检查人机难度、瞄准模式、投掷物强度和饰品开关
- 如使用自定义主题、背景或字体，建议在更新前导出个性化预设
- 玩家贴纸仍属于保留框架，不应作为本次正式版已开放功能进行测试
